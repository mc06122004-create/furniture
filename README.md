# Homestead 0.16.0

Современный мебельный мод для Minecraft 1.20.1 (Forge).

## Основные возможности
- Мебель с сидением, хранением, сном
- Кухня, ванная, компьютерная зона
- Готовка на плите и в микроволновке
- Цветовые и древесные варианты мебели
- ТВ/ПК с GUI и декодером (локальный файл / прямая .mp4)
- Частицы воды и эффекты техники

## Сборка
JDK 17, `gradle build`
